# 单文件网页

## 默认约定
- **一个 HTML 文件搞定**：样式写在 `<style>`，脚本写在 `<script>`，双击就能开，不依赖构建。
- 不引外部 CDN。必须引时先问用户能不能联网。
- 手机端优先：`<meta name="viewport" content="width=device-width,initial-scale=1">`。
- 深色/浅色用 CSS 变量，`prefers-color-scheme` 自动跟随。

## 动手顺序

1. **一句话定目标** —— 这页给谁看、看完做什么。不确定就先问，不要自己发明需求。
2. **先骨架后装饰** —— 先写出能跑的结构和交互，再加视觉。
3. **写文件** —— 用 `write_file` 落到工作目录下新建的文件夹，文件名 `index.html`。
4. **自检** —— 用 `read_file` 回看一遍，检查：标签闭合、变量名拼写、`querySelector` 的 id 是否都存在。
5. **告诉用户怎么开** —— 给出完整路径，一句话说明双击即可。

## 质量底线
- 不留 `console.log` 调试输出。
- 不留注释掉的半成品代码块。
- 按钮都要有 `:hover` 和禁用态。
- 文案用中文，不用 Lorem ipsum。
