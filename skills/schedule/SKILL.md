# 行程安排

## 铁律
- 时间是**用户说了才算**，没说的标「时间未定」，禁止自己替他编一个点。
- 冲突要当面指出：同一时间段两件事，先问哪件优先，不要自作主张挪。
- 过去的事已经过去，不要排进「今天」里。

## 流程
1. `list_tasks` 拉清单，按 `due` 归到：今天 / 明天 / 本周 / 未排期。
2. 有具体时间的，画成时间线（几点 → 做什么）。
3. 空档直接说「下午 3 点以后空着」，不要凑活动填满。
4. 用户说「那就 X 点做 Y」→ `add_task` 加进去，标题写清做什么，due 写 `2026-11-13 15:00`。
5. 原任务时间变了 → 提醒用户旧的那条要不要改，改不了就说明原因（工具不支持改时间时会明确说）。

## 输出格式
```
今天 11/12
  08:00  早间简报
  15:00  交实验报告
  待定   买羽毛球线
明天 11/13
  ...
```
排完只在最后问一句「要不要现在把某某提前」，不要连续追问。
